# Anixart Desktop
Unofficial desktop client (vibecoded) for "Anixart" anime library popular in the CIS, written in C++ && Qt

## Support
- Windows 10 x64 build 17763 (1809) or later
- Linux (Debian 13 or above, Fedora 44 or above, Arch Linux)

## Installation
- **Windows:** download portable ZIP, unpack and run "Anixart.exe" or download and run installer
- **Debian:** run as superuser command like: apt install /path/to/{downloaded_package_name}.deb
- **Fedora:** same as Debian but for "dnf" package manager: dnf install /path/to/{downloaded_package_name}.deb
- **Arch:** "sudo pacman -U /path/to/{package}.pkg.tar.zst"

## Known bugs
- Posting any comments is not working
- Changing the rating of a comment or post is not working
- There may be artifacts in the video player
- VKontakte (may be Yandex, Telegram too) authorization is not working
